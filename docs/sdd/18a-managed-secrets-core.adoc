= Overview and Core Design

== Overview

=== Problem

Valory's `ANTHROPIC_API_KEY` and `BRAVE_API_KEY` are currently injected only at
container start via environment variables.  This forces operators to restart the
container every time a key rotates, prevents deployments where the container
runtime does not expose secret injection, and offers no audit trail for
credential changes.

=== Decision Summary

[cols="1,3"]
|===
|Decision |Ruling

|Storage backend
|New `managed_secrets` table separate from `system_config`. Ciphertext and
nonce stored as `bytea`. Rationale below.

|Cipher
|AES-256-GCM with a 32-byte master key (KEK) from the `VALORY_SECRET_KEY`
environment variable, standard base64-encoded. Rationale below.

|KEK absent behaviour
|Managed-secret store is silently disabled; env-var fallback takes over. Server
logs one WARN at startup and continues. No crash.

|Hot reload mechanism
|`SecretProvider` caches resolved plaintext per name with a 30-second TTL.
On write the entry is invalidated immediately. Resolution order: managed
(if decryptable) > env var > empty string.

|Anthropic SDK per-call injection
|`anthropic-sdk-go` v1.38.0 accepts `option.RequestOption` variadic args on
`Messages.New`. `ThrottledClient` calls `SecretProvider.Get` before each call
and passes `option.WithAPIKey(key)` when non-empty, overriding the
constructor-time key without rebuilding the client.

|Brave key per-call injection
|`Professor.braveAPIKey string` field is replaced with
`Professor.secrets *SecretProvider`. `searchInternet` calls
`provider.Get(ctx, "brave_api_key")` at invocation time.

|UI masking
|Password-type inputs. Only `configured` status and last 4 characters of the
stored value are ever returned by the API. The plaintext value is never echoed
in any response.

|Audit
|`secret.set` and `secret.clear` events written to `audit_log`. Payload
contains only `{name: "anthropic_api_key"}` — no value, no last4, no hash.
`brave_api_key` is added to `redactedKeys` in `internal/audit/audit.go`.

|CLAUDE.md amendment
|Single paragraph replaces the "env-only" bullet. See section 9.

=== Why a Separate `managed_secrets` Table

`system_config` stores plaintext strings visible in `Snapshot()` and in the
`GET /admin/config` response. Adding columns or rows to `system_config` for
encrypted blobs would require every existing and future consumer of
`system_config` to explicitly exclude them. A dedicated table makes the secret
surface area explicit and narrow. It also avoids future confusion between
plaintext config values and opaque bytea blobs.

=== Why AES-256-GCM in Go, Not `pgcrypto`

`pgcrypto` symmetric encryption keeps the decryption key inside the database
session, meaning any user who can connect to the DB can decrypt. AES-256-GCM
in the Go application layer uses a key that never touches the DB. GCM
authenticates the ciphertext so tampering is detected on decryption.

=== Why `option.WithAPIKey` Per-Call, Not Client Reconstruction

The Anthropic SDK accepts `option.RequestOption` variadic args on
`Messages.New`. Passing `option.WithAPIKey(resolvedKey)` overrides the
constructor-time key for that call with zero allocation overhead. Reconstructing
the full `anthropic.Client` on key change would require a mutex-guarded pointer
swap with a race window. Per-call injection is race-free and matches the SDK's
documented design intent.

=== Why 30-Second Cache TTL

A fresh DB decrypt on every `Messages.New` call would add a DB round-trip to
every AI call. 30 seconds is short enough that a key rotation is observable
within one worker polling cycle, while long enough to eliminate DB pressure.
On explicit write or delete, the handler invalidates the cache immediately.

== Data Model

=== `managed_secrets` Table

[source,sql]
----
-- Migration: 021_managed_secrets.sql (add after existing migrations)
-- Rollback:  DROP TABLE IF EXISTS managed_secrets;

CREATE TABLE managed_secrets (
    -- Exactly one of: 'anthropic_api_key', 'brave_api_key'
    name        VARCHAR(120) PRIMARY KEY,

    -- AES-256-GCM output; variable length; bytea avoids encoding overhead.
    ciphertext  BYTEA        NOT NULL,

    -- Random 12-byte nonce (GCM standard), generated fresh per write.
    nonce       BYTEA        NOT NULL,

    -- Last 4 characters of the plaintext value, plaintext for UI display.
    last4       VARCHAR(4)   NOT NULL DEFAULT '',

    updated_at  TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_by  UUID         REFERENCES users(id) ON DELETE SET NULL
);

REVOKE ALL ON managed_secrets FROM PUBLIC;
GRANT SELECT, INSERT, UPDATE, DELETE ON managed_secrets TO valory_app;
----

No default rows are inserted. A missing row means the secret is not managed.

== Cryptography

=== Key Derivation from `VALORY_SECRET_KEY`

`VALORY_SECRET_KEY` must be standard base64-encoded 32 bytes (44 base64
characters with padding). The application decodes it at startup using
`encoding/base64`. If absent, too short, or unparseable, managed secrets are
disabled with a WARN log. No KDF is applied because the env var is a random
high-entropy value, not a password.

[source,go]
----
func loadKEK() ([]byte, bool) {
    raw := os.Getenv("VALORY_SECRET_KEY")
    if raw == "" {
        log.Printf("WARN: VALORY_SECRET_KEY not set; managed secrets disabled")
        return nil, false
    }
    kek, err := base64.StdEncoding.DecodeString(raw)
    if err != nil || len(kek) != 32 {
        log.Printf("WARN: VALORY_SECRET_KEY invalid; managed secrets disabled")
        return nil, false
    }
    return kek, true
}
----

The decoded KEK bytes live only in Go process memory. They are never written
to the database, logged, or included in any HTTP response.

=== Encryption (Write Path)

[source,go]
----
func encrypt(kek, plaintext []byte) (ciphertext, nonce []byte, err error) {
    block, _ := aes.NewCipher(kek)
    gcm, _   := cipher.NewGCM(block)
    nonce = make([]byte, gcm.NonceSize()) // 12 bytes
    io.ReadFull(rand.Reader, nonce)
    ciphertext = gcm.Seal(nil, nonce, plaintext, nil)
    return ciphertext, nonce, nil
}
----

A fresh random nonce is generated per write. The GCM authentication tag is
appended to the ciphertext by `Seal`.

=== Decryption (Read Path)

[source,go]
----
func decrypt(kek, ciphertext, nonce []byte) ([]byte, error) {
    block, _ := aes.NewCipher(kek)
    gcm, _   := cipher.NewGCM(block)
    return gcm.Open(nil, nonce, ciphertext, nil)
}
----

If `Open` returns an error (wrong key, tampered ciphertext), `SecretProvider`
logs a WARN and falls back to the environment variable.

== Secret Provider — Hot Reload

`SecretProvider` is constructed once in `main.go` and injected into
`ThrottledClient` and `Professor`.

[source,go]
----
type SecretProvider struct {
    kek   []byte        // nil when VALORY_SECRET_KEY absent/invalid
    pool  *pgxpool.Pool
    mu    sync.RWMutex
    cache map[string]secretEntry
}

type secretEntry struct {
    value     string
    expiresAt time.Time
}

const secretCacheTTL = 30 * time.Second

// Get resolves name to its current plaintext value.
// Resolution order: managed (decryptable) > env var > "".
func (p *SecretProvider) Get(ctx context.Context, name string) string {
    p.mu.RLock()
    e, ok := p.cache[name]
    p.mu.RUnlock()
    if ok && time.Now().Before(e.expiresAt) {
        return e.value
    }
    v := p.resolve(ctx, name)
    p.mu.Lock()
    p.cache[name] = secretEntry{v, time.Now().Add(secretCacheTTL)}
    p.mu.Unlock()
    return v
}

// Invalidate drops the cache entry; next Get re-decrypts from DB.
// Called by handler after PUT or DELETE succeeds.
func (p *SecretProvider) Invalidate(name string) {
    p.mu.Lock()
    delete(p.cache, name)
    p.mu.Unlock()
}

func (p *SecretProvider) resolve(ctx context.Context, name string) string {
    if p.kek != nil {
        var ct, nonce []byte
        err := p.pool.QueryRow(ctx,
            `SELECT ciphertext, nonce FROM managed_secrets WHERE name = $1`, name,
        ).Scan(&ct, &nonce)
        if err == nil {
            plain, err := decrypt(p.kek, ct, nonce)
            if err == nil {
                return string(plain)
            }
            log.Printf("WARN: managed_secrets: decrypt failed for %q: %v", name, err)
        }
    }
    return os.Getenv(strings.ToUpper(name)) // e.g. "brave_api_key" -> BRAVE_API_KEY
}
----

=== `ThrottledClient` Integration

`ThrottledClient` gains a `secrets *SecretProvider` field. Before each
`Messages.New` call:

[source,go]
----
resolvedKey := c.secrets.Get(ctx, "anthropic_api_key")
var callOpts []option.RequestOption
if resolvedKey != "" {
    callOpts = append(callOpts, option.WithAPIKey(resolvedKey))
}
msg, err = c.client.Messages.New(ctx, params, callOpts...)
----

The constructor-time key (from `ANTHROPIC_API_KEY` at startup) remains active
when `resolvedKey` is empty, preserving backward compatibility.

=== `Professor` Integration

`Professor.braveAPIKey string` is replaced with `Professor.secrets *SecretProvider`.

[source,go]
----
func (p *Professor) searchInternet(ctx context.Context, query string) string {
    key := p.secrets.Get(ctx, "brave_api_key")
    if key == "" {
        return ""
    }
    // ... existing HTTP request unchanged ...
}
----

=== Construction Order in `main.go`

[source,text]
----
pool + serverPool
  -> runMigrations
  -> configSvc.Load
  -> kek, kekOK = loadKEK()
  -> secretProvider = admin.NewSecretProvider(kek, pool)
  -> if !kekOK: log WARN once
  -> if ANTHROPIC_API_KEY == "" && !secretProvider.HasManaged("anthropic_api_key"):
       log WARN "AI features will fail until a key is configured"
  -> throttledClient = agent.NewThrottledClient(anthropicAPIKey, pool, configSvc, secretProvider)
  -> professor = agent.NewProfessor(throttledClient, serverPool, agentRepo, secretProvider)
  -> ... rest unchanged ...
----

`ANTHROPIC_API_KEY` changes from `mustEnv` to `envOrDefault(..., "")`.
The server no longer crashes on absent `ANTHROPIC_API_KEY`.

== API Contract

Routes are mounted at `/api/v1/admin/secrets`, inside the existing admin
role + CSRF enforcement group in `main.go`.

=== GET /api/v1/admin/secrets

Returns metadata for all known secret names. Values are never returned.

Response — HTTP 200:

[source,json]
----
{
  "secrets": [
    {
      "name": "anthropic_api_key", "configured": true,
      "last4": "ab1c", "updated_at": "2026-06-12T10:00:00Z",
      "source": "managed"
    },
    {
      "name": "brave_api_key", "configured": false,
      "last4": "", "updated_at": null, "source": "env"
    }
  ]
}
----

`source`: `"managed"` row exists and is decryptable; `"env"` no row but env
var is set; `"none"` neither. `last4` non-empty only for `source == "managed"`.
The env var value is never partially exposed.

=== PUT /api/v1/admin/secrets/{name}

Encrypts and upserts a managed secret.

Request body:

[source,json]
----
{ "value": "sk-ant-api03-..." }
----

Validation: non-empty (HTTP 400); max 512 chars (HTTP 422); no prefix
enforcement (avoid over-validation as key formats change).

On success the handler: encrypts value, upserts the row, writes an
`audit_log` entry in the same transaction, commits, then calls
`secretProvider.Invalidate(name)`.

Audit payload: `{"name": "anthropic_api_key"}` — no value, no last4.

Response — HTTP 200:

[source,json]
----
{
  "name": "anthropic_api_key", "configured": true,
  "last4": "ab1c", "updated_at": "2026-06-12T10:15:00Z",
  "source": "managed"
}
----

Error responses: 400 unknown name or empty value; 422 value > 512 chars;
500 encryption or DB failure (no partial write).

=== DELETE /api/v1/admin/secrets/{name}

Removes the managed secret; falls back to env var on next `Get`.

Response — HTTP 204. Returns 204 even if no row existed (idempotent; avoids
leaking existence information).

On success: calls `secretProvider.Invalidate(name)`. Audit event:
`{"action": "secret.clear", "payload": {"name": "anthropic_api_key"}}`.

== Alternatives Considered

=== Columns on `system_config`

Adding encrypted blob columns to `system_config` forces every current and
future consumer of the full config map to explicitly skip those columns.
A dedicated table is an explicit, narrow surface.

=== `pgcrypto` Symmetric Encryption

The decryption key lives inside the DB session, making it accessible to
any user who can connect. Application-layer AES-GCM keeps the key entirely
out of the DB.

=== Client Reconstruction on Key Change

Mutex-guarded pointer swap with a race window during the swap. Per-call
`option.WithAPIKey` is race-free and zero-overhead.

=== In-Memory-Only Secret Storage

Lost on restart. DB persistence is required for managed secrets to survive
container restarts.
