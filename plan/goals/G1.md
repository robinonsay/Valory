# G1 — Phase A: bug-fix & admin oversight quick wins

> Level 1. Owned by `project-manager`. Worked example (Sprints 25–26).

## Outcome

Close the small, independent gaps in admin oversight: fix the user-delete 500, show student
names instead of IDs, and give admins read-only visibility into a student's course material.
Small and independent of the Phase B epic.

## Acceptance

- Deleting a student who has had generation runs returns success with a full cascade.
- Course Oversight displays student name (ID secondary).
- Admins can read any student's syllabus, sections, content, homework, submissions, grades;
  student-to-student isolation (RLS) is preserved.
