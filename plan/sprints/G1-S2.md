# G1-S2 — Admin course-material visibility (Sprint 26)

> Level 2, goal G1. Owned by `software-lead`. Read-only oversight (PM decision).

## Scope

Give admins read-only visibility into a student's full course material: syllabus, sections,
lesson content, homework + rubric, submissions, grades. Confirm/repair the admin RLS read path
on the child tables and expose read-only admin oversight endpoints plus a frontend browser.
Admin editing/regeneration is deferred to G2's interactive flow.
