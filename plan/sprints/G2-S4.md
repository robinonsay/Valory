# G2-S4 — Interactive tree frontend, admin + student (Sprint 30)

> Level 2, goal G2. Owned by `software-lead`. The **final** sprint of Phase B. Delivers the
> root-ask **#5** UX. Frontend only — the G2-S3 HTTP/SSE API is the contract; do not change
> backend.

## Scope

The Vue interactive generation experience over the G2-S3 API/SSE: a shared tree/layer view with
per-node approve / feedback / regenerate and live SSE, wired into both the **student**
build-your-own flow and the **admin** author-and-assign flow. Existing flat-course views remain
untouched (`tree_mode = false` path).

## API surface to consume (from G2-S3, all live)
- **Student:** `GET /courses/{id}/nodes` (+ filters), `POST .../nodes/generate`,
  `POST .../nodes/{id}/refine`, `PATCH .../nodes/{id}/approve`, `PATCH .../nodes/{id}/feedback`,
  `POST .../nodes/{id}/regenerate`, `GET .../nodes/{id}/chat`,
  `POST /courses/{id}/layers/{layer}/expand`; SSE reuses `GET /courses/{id}/events` (node_* +
  layer_* event types). `GET /courses/{id}` carries the `tree_mode` discriminator.
- **Admin:** `POST/GET /admin/drafts`, `GET/DELETE /admin/drafts/{id}`,
  `POST .../nodes/generate`, `.../nodes/{id}/refine`, `PATCH approve`/`feedback`,
  `POST regenerate`, `POST .../layers/{layer}/expand`, `POST .../publish`,
  `GET .../nodes/{id}/chat`, `GET /admin/drafts/{id}/events` (SSE).
