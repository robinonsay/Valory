# G3-S2 — Cost governance: pre-flight gating + external-call budgeting (Sprint 32)

> Level 2, goal G3. Owned by `software-lead`. **Provisional** — decomposed into task contracts
> only when it becomes the active frontier (after G3-S1 lands). Builds on the S1 run lifecycle.

## Problem this sprint fixes

Paid external calls are made ad-hoc deep in generation with no run-level budget:

- The **Anthropic** per-(student,course) token cap is checked *inside* `ThrottledClient.Messages`,
  i.e. *after* `professor.searchInternet` has already fired a **Brave** call (professor.go line 95
  precedes the Claude call at line 135). So every doomed/token-capped run still burns ≥1 Brave call.
- **Brave Search has no accounting and no cap at all** — it is invoked once per `GenerateSection`
  and once per `RegenerateSection`, unbounded across runs. Combined with the S1 storm this exhausted
  a 1000-request Brave quota.
- There is no notion of a **per-run cost budget** or a unified **external-call ledger** spanning
  both providers.

## Scope (tasks decomposed when frontier)

- **Pre-flight gate:** before a run does any section/Brave/Claude work, check the student/course
  budget (tokens) and abort fast if exhausted (the S1 hook becomes a real gate). Also a
  per-section pre-check so a run that exhausts mid-way stops issuing Brave/Claude on the next
  section.
- **Brave accounting + cap + dedup:** record every Brave call (a `brave_usage` ledger or extend
  `agent_token_usage`), enforce a per-run (and per-student/day) Brave cap from config, and cache/dedup
  identical queries within a run so retries/regenerations don't re-search. Gate Brave by remaining
  budget. Make Brave entirely optional via config (degrade gracefully — it already returns "" on
  absence).
- **Unified budget model + config:** explicit per-run cost budget (tokens + searches), surfaced in
  admin config and run/escalation events so an operator can see and tune spend.
- **Tests:** a capped run makes zero external calls; Brave cap bounds calls per run; dedup proven;
  budgets enforced under `SET ROLE valory_app`.

## Requirements in scope

`REQ-SYS-074` (cost safety — the full architectural gate), new `REQ-AGENT-*` for Brave accounting +
per-run budgets.

## Definition of done (provisional)

No paid call by an over-budget run; Brave bounded + accounted per run; budgets configurable and
observable; existing generation unaffected when within budget. Held for the combined acceptance
facet.
