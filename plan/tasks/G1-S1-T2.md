# G1-S1-T2 — Regression test for delete cascade

> Level 4 task contract. Owned by `software-lead`. Worked example.

- **Worker:** test-author
- **Verifier (acceptance gate):** SQE
- **Depends on:** G1-S1-T1
- **Artifact path:** the user lifecycle integration test; summary under `plan/artifacts/G1-S1-T2/`

## Design (how — the mandate)

Extend the existing user-lifecycle integration test. Seed a course **with an `agent_runs` row
and a `pipeline_events` row** (the fixtures that previously did not exist — which is why the
500 was missed), then delete the student and assert success plus a full cascade (no orphaned
`agent_runs`, `pipeline_events`, `courses`, `submissions`, `grades`, `chat_messages`,
`sessions`). Real PostgreSQL via Docker Compose — no DB mocks. Run with `-p 1` and under
`SET ROLE valory_app` so the test exercises RLS as production does.

## Requirements (what-for)

- **REQ-USER-007** — verifies the new acceptance criterion (deletion succeeds with generation
  runs present).

## Acceptance (done-criteria)

- [ ] Test seeds `agent_runs` + `pipeline_events` before deletion.
- [ ] Asserts deletion success and a complete cascade (no orphans in any child table).
- [ ] Runs against a real database (no mocks), `-p 1`, under `SET ROLE valory_app`.
- [ ] Test carries a `@{"verifies", ["REQ-USER-007"]}` annotation; name describes behavior.
- [ ] Fails against the pre-fix code, passes against G1-S1-T1's fix.
