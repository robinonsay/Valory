## Design (how — the mandate)

`CourseRepository.ListCourses` ([internal/course/repository.go:167](../../internal/course/repository.go#L167))
feeds the admin `GET /api/v1/courses` path with a `CourseRow` carrying only `student_id` — no
username/email. On the **admin path only**, join `users` to include `student_username` and
`student_email`; leave the student path unchanged. Update `CourseRow`/the response shape and the
handler accordingly. Parameterized queries only; no N+1 (single join, not per-row lookups).
