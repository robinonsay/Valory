## Design (how — the mandate)

Add a repository for the **admin-authoring** draft tree (`course_drafts` + `draft_nodes` + the
`draft_node_id` side of `node_chats`). Data-access only — **no orchestrator, no Chair, no HTTP,
no publish/copy logic** (publish→`assignOneStudent` is G2-S3). Model it on existing
`internal/admin/` repository conventions (look at the assignment repository) and on
`internal/agent/repository.go`: pgx, `context.Context` first, parameterized queries only,
request-scoped connection for RLS.

### Required methods (names indicative)

- `CreateDraft(ctx, conn, draft) (uuid.UUID, error)` — insert `course_drafts` (admin_id, title,
  topic, level, parameters, status default `draft`). Per api-sse §10.2, also insert the
  implicit `root` `draft_nodes` row holding topic/level in payload.
- `GetDraft(ctx, conn, draftID) (Draft, error)`; `ListDrafts(ctx, conn, adminID, opts)` with
  `status` filter + cursor pagination (base64 `created_at,id`, mirror existing list idiom).
- `DeleteDraft(ctx, conn, draftID) error` — only when `status='draft'`; cascade handles
  draft_nodes + node_chats.
- `UpdateDraftStatus` / `SetDraftCurrentLayer` (sets `course_drafts.status` text +
  `current_layer node_type_enum`).
- `CreateDraftNode`, `GetDraftNode`, `ListDraftNodes(ctx, conn, draftID, opts)` (node_type /
  parent filters), `ListDraftNodeChildren`.
- `TransitionDraftNodeStatus(ctx, conn, nodeID, from, to) (bool, error)` — atomic test-and-set
  (same guard semantics as the student repo, api-sse §10.4).
- `SetDraftNodePayload` for generation completion.
- `LayerAggregate(ctx, conn, draftID, nodeType) (approved, failed, pending int, error)`.
- `node_chats` (draft-node side): `AppendDraftNodeChat(ctx, conn, draftNodeID, role, content)`,
  `ListDraftNodeChats(ctx, conn, draftNodeID) ([]NodeChatMessage, error)` ordered by
  `created_at` (covers admin chat GET api-sse §5.1.12).

### RLS / connection rules

- All access takes a **request-scoped connection** carrying the admin's
  `app.current_user_id`/`app.current_role='admin'` GUCs so the `course_drafts_admin_own` /
  `draft_nodes_admin_own` policies apply. Never the bare pool for RLS-governed access (memory
  `force-rls-superuser-test-masking`). Server-pipeline writes run with `app.current_role=
  'server'`; keep the queryer a parameter.
- Parameterized queries only.

### Scope guards

- Only `course_drafts`, `draft_nodes`, and the `draft_node_id` side of `node_chats`. The
  student `course_nodes` repo is G2-S2-T2 (separate worker, `internal/agent/`). **Do not touch
  `internal/agent/`.**
- No Chair/prompt logic, no HTTP handler, no publish/assign copy — those are G2-S3.
