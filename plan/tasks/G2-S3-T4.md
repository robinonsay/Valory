## Design (how — the mandate)

Implement the **admin-authoring** surface per
[knowledge-tree-api-sse.md §5.1, §5.3.1, §7](../../docs/design/knowledge-tree-api-sse.md). Mount
under a new `/api/v1/admin/drafts` group with `auth.RequireRole("admin")` + `security.CSRFMiddleware`,
alongside the existing admin assignment routes (~`cmd/server/main.go:526`/`551`).

### Endpoints (exact paths/methods/codes — api-sse §5.1)
- `POST /admin/drafts` → 201 (CreateDraft; **tx-wrapped** draft+implicit-root insert, D13).
- `GET /admin/drafts` (status filter + cursor) → 200.
- `GET /admin/drafts/{draftId}` → 200 {draft, nodes}.
- `DELETE /admin/drafts/{draftId}` → 204 (only `status='draft'`; 409 DRAFT_ALREADY_PUBLISHED).
- `POST /admin/drafts/{draftId}/nodes/generate` → 202; background goroutine
  `Chair.GenerateNode(isDraftContext=true)`; optional params → prompt context.
- `POST /admin/drafts/{draftId}/nodes/{nodeId}/refine` → 202; required `message` → user
  node_chats (draft side); goroutine `Chair.RefineNode`.
- `PATCH /admin/drafts/{draftId}/nodes/{nodeId}/approve` → 200.
- `PATCH /admin/drafts/{draftId}/nodes/{nodeId}/feedback` → 200; **only rejection path**;
  required non-empty `feedback` → user node_chats + payload.feedback; → rejected.
- `POST /admin/drafts/{draftId}/nodes/{nodeId}/regenerate` → 202.
- `POST /admin/drafts/{draftId}/layers/{layer}/expand` → 200 {next_layer, inserted_node_count};
  **D11: insert child draft_nodes (pending) then enqueue one background goroutine per child
  calling `Chair.GenerateNode(isDraftContext=true)`** — NOT the poller/LayeredRunner. Precondition:
  current layer fully approved (else 409 LAYER_NOT_FULLY_APPROVED); content layer → 409
  TREE_ALREADY_COMPLETE.
- `POST /admin/drafts/{draftId}/publish` → 200 {assignment_id, draft}; precondition ALL nodes
  `approved` (else 409 DRAFT_HAS_UNAPPROVED_NODES); creates or updates a `course_assignments`
  row recording `draft_id`; sets draft `status='published'`. **Tx-wrapped** (D13).
- `GET /admin/drafts/{draftId}/nodes/{nodeId}/chat` → 200 ordered draft node_chats.
- `GET /admin/drafts/{draftId}/events` → SSE via `GetEventsAfterForDraft` (T1); `RequireRole
  ("admin")`, no CSRF (GET).

### Publish→assign copy (`assignment_service.go`, api-sse §7.2)
When `AssignStudents`/`assignOneStudent` runs for an assignment that has a `draft_id`, **copy
`draft_nodes` → `course_nodes`** (status reset to `pending`, `course_id`=the new course, set
`courses.tree_mode=true`) instead of calling `GenerateSyllabusFromParams`. **Tx-wrapped** so a
course never ends up half-copied (D13). Non-draft assignments keep the existing synchronous
syllabus path unchanged (coexistence).

### Binding rules
- **Admin ownership** on every endpoint: the draft must belong to the calling admin
  (`admin_id = current_user_id`). Use the request-scoped conn (carries `app.current_user_id` +
  `app.current_role='admin'`) so the `course_drafts_admin_own`/`draft_nodes_admin_own` policies
  apply. Return 403 (admin authenticated, other admin's draft) vs 404 (no row) per api-sse §8.6.
- **D12 — draft_nodes writes on the SERVER pool** after the ownership check; reads via the
  request-scoped conn (RLS admin-own).
- **Concurrency guard:** generate/refine/regenerate atomic test-and-set via `TransitionDraftNodeStatus`;
  rowsAffected!=1 → 409 (NODE_ALREADY_GENERATING / NODE_NOT_REVIEWABLE / NODE_NOT_REGENERABLE).
- **Validate status strings** before `Transition*`/`UpdateDraftStatus` (draft tables use TEXT, not
  enums — G2-S2 caller note).
- Background goroutines use detached `context.Background()`; create `agent_run` via
  `CreateRunForDraft` (draft-anchored) for event anchoring; emit node_generating →
  node_ready/node_error via `EmitNodeEvent`.
- Reuse the draft repo (G2-S2-T3) + Chair (T1) — do not reimplement. No schema/migration changes.
- Annotate `@{"req", ["REQ-SYS-077", "REQ-SYS-074", "REQ-AGENT-0nn", ...]}`.
- Go toolchain `/usr/local/go/bin` → `export PATH=/usr/local/go/bin:$PATH`; `go build ./...` +
  `go vet ./...` clean. Do NOT rebuild/stage the `server` binary.
