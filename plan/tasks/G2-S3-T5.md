## Design (how — the mandate)

Real-Postgres integration tests (NO mocks) validating the **student** layered-generation engine
+ HITL surface end to end. This is the **runtime validation** the engine's gate-1 deferred. Match
the existing harness: `//go:build integration`, `VALORY_TEST_DATABASE_URL`, `db.IntegrationPool`/
`AcquireAsUser`/`AcquireAsServer`, `-p 1` (memory `valory-db-test-drift`), all RLS assertions
under `SET ROLE valory_app` (memory `force-rls-superuser-test-masking`).

**Stub the Anthropic call**, not the DB: the LayeredRunner/Chair call Claude — inject a fake
`Chair`/client (or a test seam) that returns canned node payloads so tests are deterministic and
free. Do NOT hit the paid API. (The reviewer's citation loop only runs for `content` nodes per
D15a; stub the reviewer decision too where needed.)

### Required coverage
1. **Layer advance happy path:** seed a tree-mode course (root+syllabus pre-approved, section_goal
   pending) → `GenerateLayer` drives section_goal nodes to `awaiting_review` → **assert the course
   transitions to `awaiting_layer_approval` and a `layer_awaiting_review` event is emitted** (this
   is the showstopper the gate caught — prove `settleLayer` now reaches the HITL gate) → student
   `PATCH approve` each node → `POST /layers/section_goal/expand` inserts concept children +
   sets `generating` → poller generates concept layer → repeat to `content` → course `active`.
2. **Regenerate on feedback:** `PATCH /feedback` (required non-empty; empty → 400) moves a node to
   `rejected` + stores feedback in node_chats + payload.feedback → poller (`awaiting_regeneration`)
   re-generates → back to `awaiting_review`.
3. **Per-layer token budget (D14):** with `per_layer_token_budget` small, a node exceeding it
   transitions to `failed` (reason `token_budget_exceeded`); confirm the budget is enforced for
   correction-loop re-calls too (the gate's cost finding).
4. **Expand precondition:** `/expand` before all nodes approved → 409 LAYER_NOT_FULLY_APPROVED;
   expand at `content` → 409 TREE_ALREADY_COMPLETE.
5. **Stuck-node recovery:** a node `generating` with stale `updated_at` is reset to `pending`.
6. **HITL endpoint authz + RLS under `SET ROLE valory_app`:** a student can only act on their own
   course's nodes (cross-student → 404/denied); the node write path is server-pool (D12); the
   concurrency guard returns 409 NODE_ALREADY_GENERATING on a double generate.
7. **Flat-course regression:** a `tree_mode=false` course still follows the flat path untouched
   (smoke check that flat generation/poll is unaffected).

Each test carries `// @{"verifies": ["REQ-SYS-073", "REQ-SYS-074", "REQ-AGENT-0nn", ...]}`.
