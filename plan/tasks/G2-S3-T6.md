## Design (how — the mandate)

Real-Postgres integration tests (NO DB mocks) validating the **admin-authoring** flow end to end:
the draft HITL handlers (T4) + the publish→assign copy. **Stub the Anthropic/Chair call** (inject
a fake returning canned node payloads) — deterministic and free; do NOT hit the paid API.

Match the harness: `//go:build integration`, `VALORY_TEST_DATABASE_URL`, `db.IntegrationPool`/
`AcquireAsUser`/`AcquireAsServer`, `-p 1` (memory `valory-db-test-drift`). All RLS/authz
assertions under `SET ROLE valory_app` (memory `force-rls-superuser-test-masking`) — no
superuser-masked assertions. Model on `internal/admin/oversight_rls_integration_test.go`
(HTTP+RLS) and `internal/admin/draft_repository_integration_test.go`.

### Required coverage
1. **Draft lifecycle:** `POST /admin/drafts` creates a draft + implicit `root` node; `GET` list
   (status filter + cursor) + `GET {id}`; `DELETE` succeeds on `draft`, returns 409
   DRAFT_ALREADY_PUBLISHED on a published draft.
2. **Per-node HITL:** generate (202, stubbed Chair drives node→awaiting_review), refine,
   `approve`, `feedback` (required non-empty → 400; stores feedback in draft node_chats +
   payload.feedback → rejected), regenerate. Concurrency: double-generate → 409.
3. **Expand (D11):** `/layers/{layer}/expand` precondition (all approved else 409
   LAYER_NOT_FULLY_APPROVED); inserts child draft_nodes; the per-child goroutines drive them to
   awaiting_review; content layer → 409 TREE_ALREADY_COMPLETE.
4. **Publish:** precondition ALL nodes approved (409 DRAFT_HAS_UNAPPROVED_NODES otherwise);
   creates/updates a `course_assignments` row with `draft_id`; draft → `published`.
5. **publish→assign copy (the key integration):** with a published draft-backed assignment,
   `AssignStudents`/`assignOneStudentDraft` produces a student course with `tree_mode=true` whose
   `course_nodes` mirror the `draft_nodes` — **assert the tree shape is preserved (parent_id
   correctly remapped), node status reset to `pending`, course_id set**. The non-draft assignment
   path still uses the synchronous syllabus flow (smoke check unchanged).
6. **Cross-admin authz + RLS under `SET ROLE valory_app`:** admin A cannot get/mutate admin B's
   draft or draft nodes (403/404, non-vacuous — seed admin B's draft + prove B sees it);
   node-belongs-to-draft binding (own draftId + foreign nodeId → 404); a student-role connection
   sees no drafts.

Each test carries `// @{"verifies": ["REQ-SYS-077", "REQ-SYS-074", "REQ-AGENT-0nn", ...]}`.
