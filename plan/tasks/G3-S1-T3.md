## Design (how — the mandate)

Give the poller a **declarative, bounded eligibility** rule and the durable state it needs, per the
T1 TDD. Two files:

1. **`migrations/024_generation_run_lifecycle.sql`** — additive, idempotent (BEGIN/COMMIT,
   self-record in `schema_migrations`, `IF NOT EXISTS` / `DO $$…EXCEPTION` guards, matching 021–023):
   - Add the terminal **`generation_failed`** course status (enum value or status CHECK — match how
     `courses.status` is currently constrained; T1 specifies). It must be a value the eligibility
     query never selects and that the existing flat/tree flows never accidentally enter.
   - Add a covering **index** for the eligibility query on `agent_runs (course_id, run_type, status,
     started_at)` so the added NOT-EXISTS sub-selects stay cheap at poll cadence.
   - No cost columns (that is G3-S2). Keep the migration minimal.

2. **`internal/agent/repository.go`** — make eligibility bounded and expose attempt state:
   - **`ListUntriggeredApprovals`**: in addition to excluding running/completed runs, exclude a
     course with a **failed same-type run inside the backoff window** (subsumes/replaces the interim
     emergency backoff clause) **and** exclude a course already in terminal `generation_failed`.
     Backoff window from config (default per T1). Keep the `(CASE … END)::agent_run_type` cast
     (regression already fixed) and the `tree_mode` branch.
   - **Consecutive-failure read**: a method returning how many same-type runs have failed since the
     last non-failed run for a course (the runner/T4 uses it to decide max-attempts → terminal).
   - All queries parameterized; reads on the appropriate connection (server pool is correct here —
     the poller has no request context); preserve the existing `CourseStudentRow` shape (+ any
     additive field T4 needs).

## Acceptance (done-criteria)

- [ ] Migration 024 is additive, idempotent, self-records, and applies cleanly on a fresh DB *and*
      on the current populated DB; adds `generation_failed` + the eligibility index only.
- [ ] `ListUntriggeredApprovals` excludes: running/completed runs (unchanged), failed-within-backoff,
      and `generation_failed` courses; backoff is config-driven; flat+tree branch intact; enum cast
      intact.
- [ ] A consecutive-failure-count read exists for the runner, parameterized, correct across the
      "since last success" boundary.
- [ ] `go build ./... && go vet ./internal/agent/...` clean; integration assertions live under

      masking).
